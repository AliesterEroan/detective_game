## 🚀 Getting Started

### Quick Start

1. **Launch the game**
   ```bash
   launch_game.bat
   ```

2. **Open in browser**
   - Navigate to the provided URL
   - Start investigating!

### Manual Setup

**Backend Setup:**
```bash
# Install dependencies
pip install -r requirements.txt

# Run the game
python src/main.py
```
